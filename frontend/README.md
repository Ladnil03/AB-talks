# AI Interview Agent — Frontend Application

Modern React & TypeScript web client for the AI Technical Interviewer platform.

---

## 🛠️ Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Vanilla CSS Design System with dark-mode glassmorphism and modern typography (`Outfit`, `JetBrains Mono`)
- **API Client**: Fetch-based client communicating with backend `/api/interview`

---

## 🏃 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Production build
npm run build
```
